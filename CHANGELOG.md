# Changelog

## 1.0.0 — draft, unpublished

First Windows 11 x64 release candidate: XInput buttons, triggers and stick directions mapped to keyboard; shared bindings and hysteresis; native settings/key capture; TOML persistence; tray controls; single-session instance ownership; disconnect and power/session recovery; bounded best-effort cleanup.

Release preparation adds generated executable versions, static CRT, baseline x64 compatibility, Windows CI, portable ZIP packaging with provenance and SHA-256, third-party notices, and user documentation.

One controller/profile; virtual-key output; no mouse, macros, chords, startup registration or updater. Protected applications may reject injection. The candidate is unsigned. Physical-input acceptance, clean-machine execution, visual DPI/accessibility checks, extended stability, and hosted CI remain release gates. See the source release-readiness report for actual results.
